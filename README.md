# AI-Оценщик ювелирных изделий

> Интеллектуальная система предварительной онлайн-оценки золотых украшений по фотографии с автоматической интеграцией в CRM для сети ломбардов СКС Ломбард.


---

## Суть продукта

Мы создали MVP продукт, который решает главную боль ломбардов — снижение барьера входа для клиента.

### Проблема
- Клиенты боятся сдавать золото в ломбард, потому что не знают, сколько им дадут
- Страх быть обманутым останавливает потенциальных заемщиков
- Ломбарды теряют клиентов, которые уходят, не узнав предварительную стоимость

### Наше решение
Клиент получает предварительную сумму дома, загрузив фото украшения. А ломбард получает **"горячего" лида** в CRM с полной информацией об изделии.

## Реализованный функционал

### 1. Анкета пользователя
- Выбор типа изделия (Кольцо, Серьги, Браслет, Кулон, Цепь, Колье)
- Выбор пробы металла (375, 585, 750, Невозможно определить)
- Указание наличия вставок (камней)
- Оценка состояния (Как новое, Среднее, Плохое)
- Ввод веса (опционально)
- Загрузка 1-2 фотографий с drag-and-drop

### 2. AI-анализ изображений
```
Пользователь загружает фото
         ↓
   Mistral AI анализирует
         ↓
┌────────────────────────────────────────┐
│  is_jewelry: boolean     — золото ли?  │
│  detected_type: string   — тип изделия  │
│  has_inserts: boolean   — есть камни?  │
│  has_visual_defects: boolean          │
│  damaged_inserts: boolean             │
│  defect_description: string          │
│  condition_assessment: string        │
└────────────────────────────────────────┘
```

### 3. Расчёт стоимости (`calculator.py`)

| Параметр | Формула |
|----------|---------|
| **База** | `Вес × Цена_пробы × Коэфф_типа × Коэфф_состояния` |
| **Наличие камней** | `-5%` от стоимости (берём только металл) |
| **Визуальные дефекты** | `-10%` (царапины, потертости) |
| **Повреждённые вставки** | `-15%` |
| **Сумма займа** | `80%` от итоговой стоимости |
| **Сумма выкупа** | `95%` от итоговой стоимости |

### 4. Интерактивная карта филиалов
- 53 филиала в Уфе с адресами
- Отображение режима работы

### 5. Интеграция с Bitrix24 CRM
**Для работы данной функции необходимо вписать в код BITRIX24_WEBHOOK_URL.**

При оформлении заявки в CRM автоматически создаётся лид с:
- ФИО и телефоном клиента
- Предварительной суммой займа/выкупа
- Отчётом ИИ о дефектах
- Загруженными фотографиями
- Выбранным филиалом

## API Endpoints

### `POST /api/v1/estimate`
Предварительная оценка изделия.

**Request (multipart/form-data):**
| Поле | Тип | Обязательно |
|------|-----|------------|
| `item_type` | string | ✓ |
| `purity` | string | ✓ |
| `has_inserts` | string ("true"/"false") | ✓ |
| `condition` | string | ✓ |
| `weight` | float | Нет |
| `photos` | file[] (1-2 шт.) | ✓ |

**Response:**
```json
{
  "loan_amount": 3200,
  "buyout_amount": 3800,
  "probability": "Средняя вероятность",
  "ai_report": {
    "is_jewelry": true,
    "detected_type": "Кольцо",
    "has_inserts": false,
    "condition_assessment": "Среднее",
    "has_visual_defects": true,
    "damaged_inserts": false,
    "defect_description": "Потертости на поверхности",
    "other_visual_features": "Жёлтое золото, гладкая поверхность"
  },
  "warning_message": "Расчёт является предварительным..."
}
```

### `POST /api/v1/create-lead`
Создание лида в Bitrix24.

**Request (application/json):**
```json
{
  "name": "Иванов Иван Иванович",

  "client_data": { ... },
  "ai_results": { ... },
  "calculation": { ... },
  "photos_base64": ["base64...", "base64..."]
}
```

### Предварительные требования
- Python 3.10+
- Node.js 18+
- API-ключ Mistral AI
- API-ключ Yandex Maps


## Важные замечания

### Определение веса
> По фотографии невозможно определить точный вес изделия. Наша логика:
> - Если клиент знает вес — он вводит его вручную
> - Если нет — подставляем статистически средний вес для этого типа (кольцо = 3 г)
> - Окончательный вес определяется только на весах в ломбарде

### Антифрод
Система использует мультимодальную LLM для распознавания:
- Золотых украшений vs других объектов (кот, машина, часы)
- Отсеивание заведомо невалидных заявок на этапе AI-анализа
